# Waypoint Web Application

## Quickstart Setup
1. Clone repository: `git clone https://github.com/GT-Codeur/waypoint-project.git && cd waypoint-project`
2. Create & activate environment: `python -m venv env && source env/bin/activate`
3. Install dependencies: `pip install -r requirements.txt`
4. Run database migrations: `python manage.py migrate`
5. Start local server: `python manage.py runserver`
